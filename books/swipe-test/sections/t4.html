滑动翻页

  1. 正文空白处向左划 → 翻到下一节
  2. 正文空白处向右划 → 回到上一节
  3. T1→T4 能一路划完；T4 向左划没有反应（已是最后一节）
  4. T1 向右划没有反应（已是第一节）
  5. 垂直上下滚动 → 不翻页
  6. 斜着划（大概 45°）→ 不翻页
  7. 最左侧 30px 以内向右划 → 不翻页
  8. 双指捏合缩放 → 不翻页

护栏：不该翻的时候别翻

  1. 在 s 平面图（polezero）上横向拖 → 只动极点，页面不动
  2. 在根轨迹图上横向划 → 页面不动
  3. 在 ζ / ωn 滑杆上左右拖 → 只动滑块，页面不动
  4. 点四个分段按钮 → 只切换情形，页面不动
  5. 在超宽代码块上横向划 → 只滚动代码，页面不动

其他
