Sensitivity to Parameter Changes

Franklin §4.1.4。这一节只回答一件事：某个块的参数变了，输出跟着变多少——以及反馈把这件事压下去多少。

定义：两个相对变化之比

你的原话对于 serial block 应该对单个 block 使用闭环公式来求解 Sensitivity，也就是某个 para 对控制器的影响
纠正 / 补全：

你说对的那一半正好是最重要的那一半。书里 §4.1.4 只推导了一块：由 $T_{cl}=\dfrac{GD_{cl}}{1+GD_{cl}}$ 得到 $S=\dfrac{1}{1+GD_{cl}}$；串级（好几块串在一起）书里没写。而"对单个 block 用闭环公式"恰好能把它补上。

定义（式 4.18–4.21）：敏感度是两个相对变化之比，不是绝对变化之比：

$$S_{G}^{T}\;\triangleq\;\frac{\delta T/T}{\delta G/G}\;=\;\frac{G}{T}\frac{dT}{dG}$$

开环：$T_{ol}=GD_{ol}$ ⇒ $\dfrac{\delta T_{ol}}{T_{ol}}=\dfrac{\delta G}{G}$ ⇒ $S=1$。参数错 10%，输出就错 10%——一点忙都帮不上。

闭环（单位反馈）：把 $T_{cl}=\dfrac{GD_{cl}}{1+GD_{cl}}$ 代进去得到

$$S=\frac{1}{1+GD_{cl}}=\frac{1}{1+L},\qquad L=GD_{cl}\ \text{（回路增益）}$$

现在回答"串级怎么办"。把前向通路拆成串级 $\mathcal{G}=G_{1}G_{2}G_{3}$，反馈为 $\mathcal{H}$：

$$T=\frac{\mathcal{G}}{1+\mathcal{G}\mathcal{H}},\qquad L=\mathcal{G}\mathcal{H}$$

对任何一块 $G_i$ 求敏感度（设 $R$ 为其余各块之积，则 $\mathcal G=G_iR$）：

$$S_{G_i}^{T}=\frac{G_i}{T}\frac{\partial T}{\partial G_i}=\frac{G_i(1+L)}{\mathcal{G}}\cdot\frac{\mathcal{G}/G_i}{(1+L)^{2}}=\boxed{\frac{1}{1+L}}$$

与 $i$ 无关。所以：前向串级里每一块的敏感度都等于同一个 $\dfrac{1}{1+L}$——参数在控制器里、在功率级里、还是在被控对象里，只要还在前向通路上，答案就是这一个数。这就是"对单个 block 使用闭环公式"的完整含义。

但反馈块不一样。$mathcal{H}$ 在分母上：

$$S_{\mathcal{H}}^{T}=\frac{\mathcal{H}}{T}\frac{\partial T}{\partial \mathcal{H}}=-\frac{\mathcal{G}\mathcal{H}}{1+L}=-\frac{L}{1+L}$$

负号不只是符号问题：它说明 $\mathcal H$ 变大会让 $T$ 变小。所以"传感器不准"和"被控对象不准"在反馈系统里的后果根本不是一回事——$L$ 大时 $|S_{\mathcal H}|\approx1$，几乎没被压下去。

两个基本功：

$$S\triangleq\frac{1}{1+L},\qquad T\triangleq\frac{L}{1+L}=1-S,\qquad S+T=1$$

两个容易踩的地方：① $T=\dfrac{L}{1+L}$ 只在 $\mathcal H=1$（单位反馈）时成立；$\mathcal H\neq1$ 时 $T=\dfrac{\mathcal G}{1+L}$，但 $S$ 与 $S_{\mathcal H}$ 的式子不变。② Bode 当年定义的敏感度是倒数：$S_{\text{Bode}}=1+L$——读别的书时先确认用的是哪套约定。

数字口径：原书举例用的是 $1+GD_{cl}=100$（即 $L=99$），于是 $S=0.01$、参数错 10% → 输出错 0.1%、开环比闭环敏感 100 倍。下面组件默认取 $L=100$，对应 $S=1/101=0.0099$、输出错 0.099%、敏感 101 倍——是同一件事，只是取整位置不同。

总结：加大全局回路增益，前向通路的参数就越来越不算数

你的原话global feedback loop 提供更大的环路 gain，有效降低了 overall transfer function 对前向路径 para 的变化的 sensitivity
纠正：对，而且这正是反馈最核心的作用（Black 1927 年就是为了它发明负反馈的）。机制就是上一条：前向串级里任何一块的敏感度都是 $S=\dfrac{1}{1+L}$，所以 $L$ 越大，前向参数的变化传到输出的比例越小；极限 $L\to\infty$ 时 $T\to\dfrac{1}{\mathcal H}$，整体传函完全由反馈元件决定。只补一句限定：这个"降低"是频率的函数，只在 $|L(j\omega)|$ 大的频段成立（$|L|$ 落到 1 附近时 $|S|$ 反而会出现峰值）。
要写下来的符号形式

定义：$S_G^T=\dfrac{\delta T/T}{\delta G/G}=\dfrac{G}{T}\dfrac{dT}{dG}$。

开环 $S=1$；闭环 $S=\dfrac{1}{1+L}$，$L=GD_{cl}$。

串级：前向任意一块 $S_{G_i}=\dfrac{1}{1+L}$（全都一样）；反馈块 $S_{\mathcal H}=-\dfrac{L}{1+L}$。

单位反馈：$S=\dfrac{1}{1+L}$，$T=\dfrac{L}{1+L}=1-S$，$S+T=1$。

自测（补）

  1. 回路增益 $L=100$。被控对象增益 $G$ 漂了 $10\%$，闭环输出的稳态值漂多少？开环呢？
    答案

    闭环 $S=\frac{1}{101}=0.0099$ → 输出漂 $0.099\%$；开环 $S=1$ → 输出漂 $10\%$。差 101 倍。

  2. 前向通路上串了三块 $G_1G_2G_3$（控制器、功率级、被控对象）。哪一块的参数漂移对输出影响最大？
    答案

    一样大。三块的敏感度都是同一个 $\frac{1}{1+L}$，与它是控制器还是被控对象无关——只要在前向通路上。这正是"对单个 block 用闭环公式"的意思。

  3. 反馈通路（传感器）$\mathcal H$ 的敏感度是多少？为什么和上面不一样？
    答案

    $S_{\mathcal H}=-\frac{L}{1+L}$，负的。因为 $\mathcal H$ 在分母上：$T=\frac{\mathcal G}{1+\mathcal G\mathcal H}$，$\mathcal H$ 增大让 $T$ 减小。而且 $|S_{\mathcal H}|\approx1$（$L$ 大时），远大于前向块的 $\frac{1}{1+L}$——反馈元件不准是严重得多的问题。

  4. $S+T=1$ 怎么来的？前提是什么？
    答案

    定义直接相加：$\frac{1}{1+L}+\frac{L}{1+L}=1$。前提是单位反馈（$\mathcal H=1$）；$\mathcal H\neq1$ 时 $T=\frac{\mathcal G}{1+L}$，$S+T\neq1$。
