Time-Domain Specifications

这一节按一条因果链组织，每一步都是上一步的结果：
① 极点在哪 → ② 时域图像长什么样 → ③ 从图像量出指标 → ④ 指标的 s 域几何 → ⑤ 怎么达到这些指标

① 极点的位置决定时域图像

你的原话极点的位置对时域图像的影响
纠正 / 补全：

一个极点给出一个模态：$s_k$ → $e^{s_k t}$。实部管衰减、虚部管振荡——所以只要知道极点在 s 平面哪一格，就知道波形长什么样。

  • 实部 $<0$（左半平面）→ 衰减；$=0$（虚轴上）→ 等幅；$>0$（右半平面）→ 发散
  • "快极点 / 慢极点"是相对衰减速率：$|$实部$|$ 越大越快
  • 一阶单调、二阶（共轭对）振荡
  • §3.3 只管极点；零点的影响在 §3.5 单独讲

要写下来的符号形式

一阶：$h(t)=e^{-\sigma t}$，时间常数 $\tau=1/\sigma$，且 $t=0$ 的切线终止于 $t=\tau$（式 3.59）。

二阶共轭对：$h(t)=\dfrac{\omega_{n}}{\sqrt{1-\zeta^{2}}}e^{-\sigma t}\sin\omega_{d}t$（式 3.66），$\sigma=\zeta\omega_{n}$。

② 从时域图像归纳出指标

你的原话时域指标的图像理解（先一阶再二阶）
纠正 / 补全：

指标不是凭空定义的，都是从上面那张图上"量"出来的——这是这一步的关键：先有图像，才有指标。

指标在图像上怎么量
上升时间 $t_{r}$曲线从 10% 爬到 90% 的那段时间（Franklin 的定义，Fig 3.20）
超调量 $M_{p}$峰值高出终值的那一截
峰值时间 $t_{p}$峰值出现的时刻
调节时间 $t_{s}$曲线最后一次离开 $\pm1\%$ 带的时刻（Franklin 用 $\pm1\%$）

一阶只有一个参数 $\tau$，图上有四个几何量，其中两个其实是同一件事：$t=\tau$ 处高度 $63.2\%$ ⟺ $t=0$ 的切线正好在 $t=\tau$ 处碰到终值。$\tau$ 既是时间尺度，也是初始斜率 $1/\tau$ 的倒数。

二阶由 $\zeta$ 与 $\omega_{n}$ 两个参数定死：$M_{p}$ 只由 $\zeta$ 决定（与 $\omega_{n}$ 无关），时间类指标（$t_{p},t_{r},t_{s}$）则都含 $\omega_{n}$。

看图看哪里：一阶时拖 τ，注意切线在 $t=\tau$ 处正好碰到终值；切到二阶，拖 ζ 看 $M_p$ 变，再拖 ωn 看时间轴被拉伸压缩——峰值高度不动，因为 $M_p$ 只由 ζ 决定。

要写下来的符号形式

一阶：$t_{r}=\tau\ln9\approx2.20\tau$，$t_{s}=4.6\tau$（$\pm1\%$）。

二阶：$M_{p}=e^{-\pi\zeta/\sqrt{1-\zeta^{2}}}$，$t_{p}=\dfrac{\pi}{\omega_{d}}$，$t_{r}\cong\dfrac{1.8}{\omega_{n}}$（Franklin 式 3.49），$t_{s}=\dfrac{-\ln\left(p\sqrt{1-\zeta^{2}}\right)}{\zeta\omega_{n}}$（$p=0.01$）。

③ 指标在 s 域的几何表示

你的原话时域指标的s域几何化（先一阶再二阶）
纠正 / 补全：

既然指标是从图像量的，而图像由极点决定——指标就能直接对应到极点在 s 平面上的几个几何量。四个几何量各管一个指标：

几何量图上是什么管哪个指标
$\sigma=\zeta\omega_{n}$到虚轴的水平距离衰减快慢 → $t_{s}$
$\omega_{d}$到实轴的垂直距离振荡快慢 → $t_{p}$
$\omega_{n}$到原点的距离整体时间尺度 → $t_{r}$
$\theta=\arcsin\zeta$与 $j\omega$ 轴的夹角阻尼 → $M_{p}$
$\arccos\zeta$与负实轴的夹角与 $\theta$ 互余（$\theta+\arccos\zeta=90^{\circ}$）

三条读图法则：极点往右（$\sigma$ 小）→ 衰减慢、$t_{s}$ 长；极点往上下（$\omega_{d}$ 大）→ 振荡快、$t_{p}$ 短；ζ 变而 ωn 不变 → 极点沿半径 $\omega_{n}$ 的圆弧滑动。

看图看哪里：拖 ζ，看极点是沿圆弧滑动而不是直线——因为 ωn 被固定住了。同一颜色就是同一个东西：橙色的角 ↔ 橙色的 $M_p$，蓝色的水平距离 ↔ 蓝色的 $t_s$。

补

部分分式展开 → 每一项的权重 → 谁主导早期、谁主导后期。

书上关键一句：分子（零点）只影响每一项的系数，不影响形态——形态由极点决定。原话是 "the role of the numerator … is to influence the size of the coefficient that multiplies each component"。

例 3.25：$H(s)=\dfrac{2s+1}{s^{2}+3s+2}$，极点 $s=-1,\,-2$，零点 $s=-\tfrac{1}{2}$。部分分式： $$H(s)=\frac{-1}{s+1}+\frac{3}{s+2}\qquad\Longrightarrow\qquad h(t)=-e^{-t}+3e^{-2t}$$

两个极点 → 两个模态：$e^{-t}$（时间常数 $1$，慢）与 $e^{-2t}$（时间常数 $1/2$，快）。快的衰减得快，所以它只在开头有戏。

$t$慢项 $-e^{-t}$快项 $3e^{-2t}$和 $h(t)$慢项占的比重
$0$$-1.000$$3.000$$2.000$$25\%$
$0.5$$-0.607$$1.104$$0.497$$35\%$
$1$$-0.368$$0.406$$0.038$$48\%$
$1.5$$-0.223$$0.149$$-0.074$$60\%$
$2$$-0.135$$0.055$$-0.080$$71\%$
$3$$-0.050$$0.007$$-0.042$$87\%$

两项相等的时刻：$-e^{-t}=3e^{-2t}\Rightarrow t=\ln3\approx1.10$。慢项的比重从 25% 涨到 87%——这就是"快项退场、慢项接管"。

这为什么是通往"主导极点"的门：若某个极点离虚轴远得多，它在后期几乎为零——后期响应就由最慢的那个（那对）极点决定。这就是主导极点，也是能用低阶近似代替高阶系统的依据（§3.5 正式用起来）。

要写下来的符号形式

$$\sigma=\zeta\omega_{n},\qquad \omega_{d}=\omega_{n}\sqrt{1-\zeta^{2}},\qquad \sigma^{2}+\omega_{d}^{2}=\omega_{n}^{2}$$

角度（Franklin Fig 3.18）：$$\theta=\arcsin\zeta\ \text{（从 }j\omega\text{ 轴量）},\qquad \arccos\zeta\ \text{（从负实轴量）},\qquad \theta+\arccos\zeta=90^{\circ}$$

④ 怎么达到这些指标——通过什么

你的原话最后就是怎么满足这些指标，通过什么
纠正 / 补全：

先说一句最容易误解的：你不能直接"把极点放到那里"。极点是你改增益、校正装置、反馈结构之后的结果——所以设计永远是"试 → 看极点跑到哪 → 再调"。这决定了下面三类手段的性质。

手段它改变什么能做什么 / 不能做什么
改开环增益 $K$闭环特征方程 $1+KG(s)H(s)=0$ 的解 极点沿一条固定的根轨迹滑动——只有一维自由度。$K$ 调大通常让极点往右/往上下跑（更快振荡、更小阻尼）
加零点 / 加极点
（校正装置）		根轨迹的形状本身 加左半平面零点把轨迹往左拉（更快、更稳）；加极点往右拉。这就是超前 / 滞后校正
改反馈结构把开环极点变成闭环极点的映射 自由度最大：状态反馈可以直接指定闭环极点（极点配置）

动参数之前先判稳：拉氏判据（Routh，§3.6）先给出"$K$ 在什么范围内系统才稳定"——那是根轨迹与 $\omega$ 轴的交点，是所有设计的边界。

所以这条链的落点是后面三章：

  • Ch5 根轨迹法：$K$ 变时极点怎么走——把手动试错变成看图
  • Ch6 频域设计法：用校正装置改轨迹形状——把轨迹主动"掰"到你要的地方
  • Ch7 状态空间设计：直接给定极点位置反求反馈增益（极点配置）

一句话收束：指标 → 要求极点在哪 → 用什么手段把极点挪过去。这一章教你前两步，后三章教你第三步。

自测（补）

  1. ωn 不变、ζ 从 0.7 降到 0.3，极点在 s 平面上怎么动？$M_p$、$t_s$、$t_p$ 各怎么变？
    答案

    沿半径 $\omega_n$ 的圆弧向虚轴靠近。$\sigma=\zeta\omega_n$ 变小 → $t_s=4.6/\sigma$ 变长；$\omega_d$ 变大 → $t_p=\pi/\omega_d$ 变短；$\zeta$ 变小 → $M_p$ 变大。

  2. 只调增益 $K$，能让任意系统达到任意指标吗？为什么？
    答案

    不能。$K$ 只让极点沿一条固定的根轨迹滑动，是一维自由度；要落到轨迹外的位置，必须加零点/极点（校正）或改反馈结构。

  3. 为什么说"算 $e_{ss}$ 之前要先判稳"？
    答案

    终值定理只对稳定系统成立（$sF(s)$ 极点须全在左半平面）。不稳定时它会给出一个有限但假的数——不是数学算错，是物理上根本没有终值。
