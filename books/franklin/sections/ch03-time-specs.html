纠正 / 补全：

一阶只有一个参数 τ，整条曲线由它定死。图上有四个几何量，其中两个其实是同一件事：

几何说法数值

"切线在 $\tau$ 处碰到终值"就是一阶图形的全部秘密：$\tau$ 既是时间尺度，也是初始斜率 $1/\tau$ 的倒数。

图上看到的公式只由谁决定

一阶二阶的共同点：调节时间都由"包络衰减到 $1\%$"决定——一阶 $4.6\tau$、二阶 $4.6/\sigma$。所以σ（衰减率）才是决定 $t_s$ 的那个量。这句话直接引出 SUM 2。

看图看哪里：一阶时拖 τ，注意切线在 $t=\tau$ 处正好碰到终值；切到二阶，拖 ζ 看 $M_p$ 变，再拖 ωn 看时间轴被拉伸压缩——峰值高度不动，因为 $M_p$ 只由 ζ 决定。

要写下来的符号形式

一阶 $G(s)=\dfrac{K}{\tau s+1}$，$y(t)=K(1-e^{-t/\tau})$，$t_{r}=\tau\ln9$，$t_{s}=4.6\tau$（$\pm1\%$）。

二阶 $M_{p}=e^{-\pi\zeta/\sqrt{1-\zeta^{2}}}$，$t_{p}=\dfrac{\pi}{\omega_{d}}$，$t_{s}=\dfrac{-\ln\left(p\sqrt{1-\zeta^{2}}\right)}{\zeta\omega_{n}}$（$p=0.01$）。

SUM 2　时域指标的 s 域几何化

你的原话时域指标的s域几何化（先一阶再二阶）
纠正 / 补全：

极点在 s 平面上的位置，就是时域指标的几何编码。

一阶：极点落在实轴的 $-1/\tau$。它到虚轴的水平距离就是 $1/\tau$——距离越大，衰减越快，$t_{s}$ 越短。一阶的全部信息就是这一个距离。

二阶：一对共轭极点 $-\sigma\pm j\omega_{d}$，四个几何量各管一个指标：

几何量图上是什么管哪个指标
$\sigma=\zeta\omega_{n}$到虚轴的水平距离衰减快慢 → $t_{s}$
$\omega_{d}$到实轴的垂直距离振荡快慢 → $t_{p}$
$\omega_{n}$到原点的距离整体时间尺度
$\beta=\arccos\zeta$与负实轴的夹角阻尼 → $M_{p}$

三条最实用的读图法则：

  • 极点往右移（$\sigma$ 变小）→ 衰减变慢、$t_{s}$ 变长
  • 极点往上下移（$\omega_{d}$ 变大）→ 振荡变快、$t_{p}$ 变小
  • ζ 变而 ωn 不变 → 极点沿以原点为圆心、半径 $\omega_{n}$ 的圆弧滑动（因为 $\sigma^{2}+\omega_{d}^{2}=\omega_{n}^{2}$）

看图看哪里：拖 ζ，看极点是沿圆弧滑动而不是直线——因为 ωn 被固定住了；同时 $\beta$ 变小、$\sigma$ 变大、$M_p$ 变小。三条刻度线分别是到虚轴、到实轴、到原点的距离。

要写下来的符号形式

极点 $s_{1,2}=-\zeta\omega_{n}\pm j\omega_{n}\sqrt{1-\zeta^{2}}$，于是

$$\sigma=\zeta\omega_{n},\qquad \omega_{d}=\omega_{n}\sqrt{1-\zeta^{2}},\qquad \zeta=\cos\beta,\qquad \sigma^{2}+\omega_{d}^{2}=\omega_{n}^{2}$$

自测（补）

  1. ωn 不变、ζ 从 0.7 降到 0.3，s 平面上的极点怎么动？$M_p$、$t_s$、$t_p$ 各怎么变？
    答案

    沿半径 $\omega_n$ 的圆弧向虚轴靠近。$\sigma=\zeta\omega_n$ 变小 → $t_s=4.6/\sigma$ 变长；$\omega_d$ 变大 → $t_p=\pi/\omega_d$ 变短；$\zeta$ 变小 → $M_p$ 变大。

  2. 为什么说"$M_p$ 只由 ζ 决定"？
    答案

    $M_p=e^{-\pi\zeta/\sqrt{1-\zeta^{2}}}$ 里没有 $\omega_n$。几何上：$M_p$ 只看极点的方向（与负实轴的夹角），不看它离原点多远。

  3. 一阶系统拖大 τ（极点往原点靠），$t_s$ 怎么变？为什么？
    答案

    $t_s\approx4.6\tau$ 变长。几何原因：极点在 $-1/\tau$，τ 变大 → 到虚轴的距离 $1/\tau$ 变小 → 衰减更慢。
